# Deepak Store 🛒📱

Deepak Store Android App (Grocery & General Store Shopping App)

---

## 📥 APK कैसे डाउनलोड करें (How to Download APK)

आप इस GitHub रिपॉजिटरी से बड़ी आसानी से सीधे APK फ़ाइल डाउनलोड करके अपने Android फ़ोन में इंस्टॉल कर सकते हैं:

### तरीका 1: GitHub Releases से सीधा डाउनलोड (Direct Download - Recommended)
1. इस पेज के दाईं ओर (Right side) **Releases** सेक्शन पर क्लिक करें या सीधे `Releases` टैब में जाएं।
2. सबसे ऊपर मौजूद **Latest Release** पर जाएं।
3. **Assets** सेक्शन के अंदर दी गई `.apk` फ़ाइल (जैसे: `deepak-store-debug-build-X.apk`) पर क्लिक करें।
4. APK डाउनलोड होना शुरू हो जाएगा।

---

### तरीका 2: GitHub Actions Artifacts से डाउनलोड (Backup Method)
1. ऊपर मौजूद **Actions** टैब पर क्लिक करें।
2. सबसे ऊपर वाली सफल **Build & Release Debug APK** वर्कफ़्लो रन पर क्लिक करें।
3. पेज के नीचे स्क्रॉल करके **Artifacts** सेक्शन में जाएं।
4. **`app-debug-apk`** पर क्लिक करके डाउनलोड करें।

---

## 📲 APK को फ़ोन में कैसे इनस्टॉल करें (Installation Steps)

1. डाउनलोड की गई `.apk` फ़ाइल पर अपने फ़ोन में टैप करें।
2. यदि फ़ोन पूछे, तो **"Install from unknown sources"** या **"Allow from this source"** को Allow (अनुमति) दें।
3. **Install** बटन दबाएं और ऐप शुरू करें!

---

## ⚙️ ऑटोमैटिक APK बिल्ड (Automatic Builds via GitHub Actions)
इस रिपॉजिटरी में ऑटोमैटिक बिल्ड सिस्टम लगा हुआ है। जब भी कोड पुश किया जाता है, GitHub Actions अपने आप नया APK तैयार करके Releases में अपलोड कर देता है।
